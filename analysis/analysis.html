Game Analysis

Import a game from Lichess or Chess.com to get move-by-move analysis powered by Stockfish.

Red Chess Analysis lets you review any chess game in detail using the Stockfish engine. Import a game by pasting a PGN, or enter your username from Lichess or Chess.com to fetch your recent games directly. Once loaded, Stockfish evaluates every move and classifies it as Brilliant, Good, Inaccuracy, Mistake, or Blunder. You will see an overall accuracy score for both players, a phase-by-phase breakdown across Opening, Middlegame, and Endgame, plus a full move-by-move board review with the best move shown for every mistake. All analysis runs locally in your browser — no data is sent to any server.
